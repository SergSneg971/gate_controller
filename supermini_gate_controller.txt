1. ОБЩЕЕ ОПИСАНИЕ И НАЗНАЧЕНИЕ
--------------------------------------------------------------------------------
Устройство представляет собой беспроводной Zigbee-контроллер для управления 
автоматическими воротами (откатными или распашными) и контроля их положения.
Прошивка собрана в роли Zigbee Router (маршрутизатора), что позволяет контроллеру 
работать от постоянного питания и ретранслировать пакеты других Zigbee-устройств 
(включая спящие датчики на батарейках).

Основные функции:
- Импульсное управление полным открытием ворот (реле 1, импульс 500 мс).
- Импульсное управление режимом калитки / пешеходного прохода (реле 2, импульс 500 мс).
- Отслеживание фактического закрытия ворот по проводному геркону с антидребезгом 200 мс.
- Аппаратный сброс привязки к сети Zigbee (Factory Reset) по удержанию кнопки 5 секунд.
- Светодиодная индикация состояния подключения к сети.
- Сохранение сетевых ключей и привязок в энергонезависимой памяти NVRAM.


2. РАСПИНОВКА ПЛАТЫ SUPERMINI NRF52840 (PRO MICRO NRF52840)
--------------------------------------------------------------------------------
Плата имеет форм-фактор Pro Micro / Nice!Nano (24 вывода по бокам + внутренние узлы).
Ниже указаны задействованные в прошивке выводы:

[Питание]
- RAW / B+  : Вход питания (если используется встроенный стабилизатор, 3.7–5 В).
- 3.3V      : Питание 3.3 В для логики релейного модуля.
- GND       : Общий провод (земля) — объединяется с GND релейного модуля и геркона.

[Управляющие и сигнальные пины]
+-----------+---------------+----------------------------------------------------+

| Пин nRF   | Маркировка    | Назначение в проекте                               |
+-----------+---------------+----------------------------------------------------+

| P0.17     | 017 (TXO/D1)  | Реле 1: Полное открытие (активный уровень HIGH)    |
| P0.20     | 020 (D3)      | Реле 2: Калитка (активный уровень HIGH)            |
| P0.22     | 022 (D4)      | Геркон закрытия (вход с подтяжкой PULL_UP,         |
|           |               | замыкается на GND при закрытых воротах)            |
| P0.11     | 011 (D7)      | Кнопка сброса сети Zigbee (вход с PULL_UP,         |
|           |               | удержание 5 сек на GND запускает сброс и поиск)    |
| P0.15     | Встроенный    | Красный светодиод индикации состояния сети Zigbee  |
|           |               | (синий LED у разъема USB-C — индикатор заряда АКБ) |
| P0.13     | Внутренний    | Ключ питания выхода VCC (в текущей версии прошивки |
|           |               | отключен / не задействован)                        |
| RST       | RST           | Аппаратный сброс. Двойное быстрое замыкание на GND |
|           |               | переводит плату в режим USB-флешки (UF2 Bootloader)|
+-----------+---------------+----------------------------------------------------+

Примечание по реле: В прошивке задан активный уровень GPIO_ACTIVE_HIGH (срабатывание 
от подачи 3.3 В на вход IN релейного модуля). Если используется релейный модуль, 
управляемый нулем (LOW), необходимо в файле app.overlay заменить GPIO_ACTIVE_HIGH 
на GPIO_ACTIVE_LOW для узлов relay_1 и relay_2.


3. СХЕМА ПОДКЛЮЧЕНИЯ ПЕРИФЕРИИ
--------------------------------------------------------------------------------
1) Двухканальный релейный модуль:
   - VCC реле  -> 3.3V (или 5V от внешнего блока питания, если реле 5-вольтовое с опторазвязкой)
   - GND реле  -> GND платы SuperMini
   - IN1 реле  -> P0.17 (Полное открытие)
   - IN2 реле  -> P0.20 (Калитка)
   - Контакты реле (COM и NO) подключаются параллельно кнопкам управления 
     на плате привода ворот (сухой контакт: SBS / OPEN / PED).

2) Геркон (датчик положения ворот):
   - Один провод геркона -> P0.22
   - Второй провод геркона -> GND
   (Внешний резистор не требуется, используется внутренняя подтяжка nRF52840).

3) Сервисная кнопка сброса (опционально):
   - Один контакт кнопки -> P0.11
   - Второй контакт кнопки -> GND


4. СТРУКТУРА ZIGBEE (ЭНДПОИНТЫ И КЛАСТЕРЫ)
--------------------------------------------------------------------------------
Устройство представляется координатору (Zigbee2MQTT) тремя эндпоинтами:

- Endpoint 1 (EP_FULL_OPEN — Полное открытие):
  * Профиль: Home Automation (0x0104), Device ID: On/Off Output (0x0002)
  * Кластеры: Basic (0x0000), Identify (0x0003), On/Off (0x0006)
  * Логика: При получении команды ON замыкает Реле 1 на 500 мс, затем 
    автоматически отключает реле и возвращает свой статус в OFF.

- Endpoint 2 (EP_WICKET — Калитка):
  * Профиль: Home Automation (0x0104), Device ID: On/Off Output (0x0002)
  * Кластеры: Identify (0x0003), On/Off (0x0006)
  * Логика: При получении команды ON замыкает Реле 2 на 500 мс, затем 
    автоматически отключает реле и возвращает свой статус в OFF.

- Endpoint 3 (EP_REED_SWITCH — Геркон):
  * Профиль: Home Automation (0x0104), Device ID: Simple Sensor (0x000C)
  * Кластеры: Identify (0x0003), Binary Input (0x000F)
  * Логика: Передает атрибут presentValue (0x0055):
    - 0 (false) = геркон замкнут на GND (ворота ЗАКРЫТЫ)
    - 1 (true)  = геркон разомкнут (ворота ОТКРЫТЫ)


5. ИНДИКАЦИЯ И АЛГОРИТМ РАБОТЫ
--------------------------------------------------------------------------------
1) Подача питания:
   - Если устройство еще не привязано к сети Zigbee, запускается режим поиска 
     сети (Network Steering). Красный светодиод (P0.15) мигает каждые 300 мс.

2) Работа в сети:
   - После успешного входа в сеть мигание прекращается, красный светодиод горит 
     постоянно.
   - Через 3 секунды после старта/перезагрузки контроллер принудительно 
     считывает состояние геркона и обновляет статус в сети.
   - Устройство работает в режиме Zigbee Router (постоянный прием и ретрансляция).

3) Сброс привязки (Factory Reset):
   - Зажать кнопку на пине P0.11 (замкнуть на GND) и удерживать 5 секунд.
   - Устройство удалит текущую привязку из NVRAM, красный светодиод начнет мигать 
     с интервалом 300 мс, и контроллер перейдет в режим сопряжения.


6. ПРОШИВКА И ИНТЕГРАЦИЯ В ZIGBEE2MQTT
--------------------------------------------------------------------------------
1) Загрузка прошивки (UF2):
   - Подключить плату по USB-C к ПК.
   - Дважды быстро замкнуть контакты RST и GND (появится съемный диск NICENANO).
   - Скопировать файл supermini_gate_controller.uf2 в корень этого диска.

2) Подключение к Zigbee2MQTT:
   - Поместить файл внешнего конвертера supermini_gate.mjs (или supermini_gate.js) 
     в директорию zigbee2mqtt/data/external_converters/ (либо создать через веб-интерфейс
     Z2M: Настройки -> Внешние конвертеры).
   - Перезапустить Zigbee2MQTT и включить режим сопряжения (Permit join).
   - В интерфейсе появятся два переключателя (full_open, wicket) и датчик 
     открытия/закрытия (contact).


7. РЕКОМЕНДАЦИИ ПО МОНТАЖУ
--------------------------------------------------------------------------------
- Не размещайте плату SuperMini внутри герметичного металлического корпуса 
  привода ворот: металл экранирует встроенную керамическую антенну 2.4 ГГц. 
  Вынесите плату в пластиковую распаечную коробку снаружи корпуса.
- Используйте качественный блок питания 5 В с запасом по току (от 500 мА), 
  чтобы пусковые токи мотора ворот и срабатывание катушек реле не вызывали 
  просадок напряжения и перезагрузки микроконтроллера.
